Shorts Hub — Privacy Policy

Last updated: September 11, 2026

Shorts Hub is a personal tool used only by its owner to create short fact videos and publish them to the owner's own YouTube channel and TikTok account. It is not offered to the public, and it does not collect information from anyone else.

What the app accesses

  • YouTube: with the owner's permission, the app uses the YouTube Data API to upload videos (title, description, tags and the video file) to the owner's channel. It requests only the youtube.upload permission. It does not read, change or delete any other YouTube data.
  • GitHub: finished videos and their details are stored in the owner's private GitHub repository.
  • Google Gemini: topic ideas are sent to Google's Gemini API to write video scripts. No personal information is included.

What is stored and where

Access keys are kept in the owner's own browser (local storage) and in encrypted GitHub repository secrets. They are never shared with third parties. Videos are kept in the owner's private repository for up to 30 days, then removed automatically.

Sharing

No data is sold or shared. Data is sent only to the services listed above, and only to carry out the owner's own requests.

Revoking access

YouTube access can be removed at any time from the Google Account's security settings: myaccount.google.com/permissions.

Third-party terms

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Contact

Questions: open an issue or contact the owner via github.com/thmarine24-blip.
